Supper Ledger app map

A take-home guide to where things live. Supper Ledger is the night-of ledger for a benefit dinner: the organizer pastes the group chat and sees money against the goal, plates per pickup slot and who still owes. It runs entirely in the browser; nothing is sent anywhere.

The main pieces

  • The reader (src/ledger/parse.ts) turns chat lines into orders and payments with plain rules, in English and Spanish. No AI model and no API key.
  • The ledger (src/ledger/apply.ts, totals.ts) merges what was read into the people list and adds up money, plates and slots. Every change returns a new copy.
  • Storage (src/ledger/storage.ts) keeps the ledger in the browser's local storage under supper-ledger:v1.
  • The screens (src/App.tsx and src/components/) show the welcome, setup and the board with the thermometer.

One action, end to end: pasting the group chat

Reference route

A route to follow on your own. It was not toured together during the build.

  1. src/components/PasteBox.tsx, search handleSubmit. Pressing "Add to ledger" hands the pasted text to onAdd, which App wires to handlePaste.
  2. src/ledger/parse.ts, search export function readLine. One chat line becomes a name, plates, a payment and a pickup time. The Spanish and English keyword lists sit at the top in EN and ES.
  3. src/ledger/apply.ts, search export function applyPaste. It skips lines already added, finds or creates each person, snaps the time to the nearest pickup slot, and records what was read in lastPaste. The board then recomputes with computeTotals in src/ledger/totals.ts.

A practice to reuse

Each requirement in devpost/prd.md was written as something you can observe, then pinned to a numbered test. When the Spanish slice landed, test 26 ("Tía Rosa 4 platos, yapeó 2") failed even though the code looked right. The failing assertion pointed straight at the reader: a capture group in plin(e[oó])? was stealing the amount. On the next project, write the example sentence before the code and turn it into a test first; the bug then shows up as a red line instead of a wrong number on the night.

Run it again

From app/: npm install, then npm run dev and open the address it prints (path /supper-ledger/). Tests: npm test.
